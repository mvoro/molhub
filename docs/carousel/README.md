# Карусель

Раздел `/carousel` реализован на существующих компонентах AI Hub/shadcn. Исходный сценарий и 20 изображений стилей перенесены из `composer-chat`; UI собран под типографику, токены, Hugeicons, AppSheet и FileViewer AI Hub.

## Сценарий

1. Шаблоны: 20 стилей и свой стиль, поиск, категории, выбранный стиль. На узком экране настройки открываются через общий AppSheet по кнопке «Далее».
2. Настройки: тема/текст, аудитория, 3–10 слайдов, 1:1 / 4:5 / 9:16. Свой стиль принимает описание и до пяти JPG/PNG/WebP, до 15 МБ каждый; фото сохраняются в IndexedDB.
3. Редактор: заголовок и текст каждого слайда, изменение порядка содержательных слайдов, копирование и реальный Canvas-предпросмотр. Короткая тема даёт структуру: инструкции автору не отправляются в готовые изображения. Пустые и переполненные поля проверяются до экспорта.
4. Результат: общий FileViewer, навигация и миниатюры, PNG отдельного слайда, ZIP всей серии и копирование текста. Повтор создаёт независимую копию; замена существующего черновика требует подтверждения.
5. История: последние 12 работ на устройстве, поиск и удаление с подтверждением. Просмотр не заменяет черновик. Незавершённые правки восстанавливаются после перезагрузки, включая текст, превышающий лимит экспорта.

## Границы реализации

Как и исходник, это локальная композиция Canvas, без AI API и списаний. Описание своего стиля выбирает палитру/типографику; фотографии используются фоном, без AI-анализа. Выходные PNG имеют ширину 1080 px. История и черновики локальны для браузера; Blob фотографий не помещаются в localStorage. Новых UI-примитивов и зависимостей нет.

## Правки интерфейса · 1 октября 2026

- Убраны подзаголовок страницы, пример текста и подпись под подготовкой. Выбор стиля, количества и формата использует общий AppMenu; кнопка стиля повторяет фильтр «Все форматы» из Трендов.
- Мобильный поиск повторяет Роли, включая раскрытие в той же строке, очистку, Escape, восстановление фокуса и reduced motion. Переиспользован существующий CSS поиска.
- Палочка проверяет пустое поле, возвращает в него фокус и локально упорядочивает пробелы/абзацы с отменой через тост. AI-переписывание не подключено; пользовательские формулировки сохраняются.
- Пикер показывает только номера; незаполненные поля отмечаются сразу, с доступным описанием причины. Мобильная маска со стрелкой прокручивает к созданию и исчезает, когда CTA виден. Учитываются прокрутка, изменение размеров и экранная клавиатура.
- Отступ под нижней панелью каталога использует то же контейнерное условие, что и сама панель. На мобильном PNG заменён иконкой скачивания с подписью и Tooltip.
- Проверены 375×812, 820×800, 1075×800 и 1100×800: последние шаблоны выше панели, поиск/меню, тост, состояние неполного слайда, прокрутка к CTA и иконка PNG. `npm run build`, scoped oxlint и 33 теста проходят.
