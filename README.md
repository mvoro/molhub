# Molhub · AI Hub

Русскоязычный интерфейс AI Hub: чаты, фото, видео, музыка, роли и проекты.
React 19, TypeScript, Vite, Tailwind CSS и shadcn/ui.

**Сайт:** https://mvoro.github.io/molhub/

## Локальный запуск

Нужен Node.js 24.

```sh
npm ci
npm run dev
```

## Проверки

```sh
npm test
npm run build
npm run lint
```

Storybook: `npm run storybook` (порт 6007).

## GitHub Pages

Каждый push в `main` запускает `.github/workflows/deploy-pages.yml`:
установка зависимостей, тесты, сборка и публикация на GitHub Pages.
В Settings → Pages источником выбран GitHub Actions.

В CI `VITE_BASE_PATH=/molhub/` задаёт префикс ресурсов, навигации и ссылок.
Локальная разработка остаётся на `/`.
`404.html` содержит приложение, чтобы прямые ссылки на чаты, проекты и студии
открывались на статическом хостинге. При таком входе Pages возвращает HTTP 404,
а интерфейс восстанавливает нужный раздел.

Проверить сборку с тем же адресом локально:

```sh
VITE_BASE_PATH=/molhub/ npm run build
VITE_BASE_PATH=/molhub/ npm run preview
```

Это клиентский прототип с демоданными и локальным состоянием браузера.
GitHub Pages публикует интерфейс; сервер генерации и синхронизация между
пользователями в этот репозиторий не входят.

Для отката отмените проблемный коммит в `main` и отправьте изменение:
workflow автоматически опубликует предыдущую версию приложения.

## Демонстрационная авторизация

Новая сессия открывается в гостевом режиме: без чатов и проектов в сайдбаре.
Модель, роли, создание проекта и любые контролы композера требуют входа. У гостя вместо баланса — переключатель темы.
Просмотр инструментов и набор запроса доступны гостю; закрытие формы сохраняет черновик.

Флоу перенесён из `ideas-scroll-demo.html`: VK ID / Яндекс / Google либо email → код → успех.
Это имитация входа, не серверная аутентификация: OAuth и отправка писем не подключены.
Для проверки email-флоу подойдёт код `1234`; `0000` показывает ошибку, как в референсе.
Аккаунт показывает введённую почту. Социальный вход использует демонстрационные данные:
Google — `demo@gmail.com`, Яндекс ID и VK ID — `demo`; это не данные реального OAuth-профиля.
Повторный код доступен через 30 секунд. Закрытие формы отменяет ожидающий вход.
Демо-сессия сохраняется в `ai-hub:demo-auth-v1`; «Выйти» возвращает гостевой режим,
не удаляя ранее сохранённые чаты, проекты и песни. Для настоящей авторизации
нужно заменить имитацию в `AuthModal` серверными вызовами и проверкой сессии.
